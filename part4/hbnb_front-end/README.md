# 📘 HBNB RESTful API Project - Part 4

This part of the project introduces a frontend interface for the HBNB platform, allowing users to interact with the REST API through a modern and responsive web application. It focuses on seamless frontend-backend integration, delivering an intuitive user experience with features such as place browsing, filtering, review management, and secure authentication.

---

## ✅ Key Enhancements

**Responsive Web Interface**:

* A clean and modern UI built with HTML, CSS, and JavaScript.

**Authentication Handling**:

1. User login via JWT.

2. Secure token storage in cookies.

3. Dynamic rendering of ``Login`` / ``Logout`` links.

**User Features**:

1. Browse and filter places by price.

2. View detailed information for each place.

3. Display and manage reviews for places.

4. Submit new reviews through an interactive form.

**Backend Integration**:
* All operations use Fetch API to consume the existing REST endpoints.

## 🚀 How to Run the Website Server

To start the local server and view the website, follow these steps:

- Open a terminal.

- Navigate to the front-end folder by running:

````
cd part4/hbnb_front-end
````

Start a simple HTTP server with Python:

````
python3 -m http.server
````
